# 뚜러뻥 대작전 (Godot 4)

**바로 하기 (핸드폰 가능):** https://gbsman77.github.io/ttureoppeong/

변기 속으로 다이빙한 주인공이 뚜러뻥을 던져 귀여운 똥괴물을 무찌르고 하수구를 뚫는 카발(Cabal) 스타일 액션 게임입니다.

## 실행 방법
1. Godot 4.3 이상(표준판, .NET 아님)을 설치합니다. https://godotengine.org/download
2. Godot 프로젝트 매니저에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택
3. 처음 열 때 폰트를 자동으로 가져온 뒤, **F5(실행)** 를 누르면 시작합니다.

그림은 `art/` 폴더의 PNG(챗GPT로 만든 그림을 잘라 정리한 것)를 씁니다. 어떤 파일이 없으면 그 부분만 코드로 그린 임시 그림이 대신 나옵니다. 소리는 모두 코드로 합성합니다. (폰트는 `fonts/Jua-Regular.ttf`, OFL 라이선스)

그림을 바꾸려면 `art/` 안의 같은 이름 파일을 덮어쓰면 됩니다. 캐릭터 그림은 투명 배경에 발끝까지 딱 맞게 잘라야 합니다 (발밑이 기준점).

## 조작
| 동작 | 키 |
|---|---|
| 이동 | A / D 또는 ← / → |
| 조준 | 마우스 |
| 뚜러뻥 던지기 | 좌클릭 (누르고 있으면 연사, J/Z 키도 가능) |
| 구르기 (무적) | Space 또는 Shift |
| 왕뚜러뻥 (범위 공격) | 우클릭 (K/X 키도 가능) |

## 게임 진행 순서
1. **시작 화면**: 로고가 통 떨어지고, 주인공이 똥괴물에게 뚜러뻥을 던지는 연출, 뒤에는 최종 보스 무지개똥. 최고 점수 표시 → 시작 버튼(아무 데나 눌러도 됨)
2. **인트로**: 주인공이 변기로 "으랏차!" 다이빙 → "풍덩!" → 물 내려가며 하수구로 출동 (Space로 건너뛰기)
3. **STAGE 1 막힌 하수구**: 똥괴물 25마리를 무찌르면 막힘 게이지가 비워짐
4. **보스 '설사' 등장**: 경고 사이렌 후 하수구 굴에서 나타남. 패턴: 똥 부채꼴 던지기 / 바닥 훑는 설사 스프레이 / 꼬마똥 소환. 체력이 절반 이하면 빨라짐
5. **보스 쓰러짐**: "설사 격파!" → STAGE 1 CLEAR (보너스 1000점, 목숨 +1)
6. **STAGE 2 무지개 하수구**: 그냥똥(튼튼함)과 녹색똥(빠르고 똥을 두 개씩 던짐) 30마리
7. **마지막 보스 '무지개똥'**: 설사의 패턴에 **무지개 똥비**(천장에서 쏟아짐)가 더해짐
8. **클리어**: 꾸르륵... → **펑!** 하고 변기가 뚫리며 물기둥 + 주인공이 튀어나옴 → **쾌변!** 팡파레

## 시스템
- 뚜러뻥에 맞으면 똥괴물 얼굴이 **맞은 얼굴(>_<)** 이 되고, 뚜러뻥이 얼굴에 잠깐 붙습니다.
- 같은 괴물을 0.9초 안에 **연속 4번** 맞히면 **치명타!** (3배 데미지, 소용돌이 눈 치명타 얼굴, 기절)
- 똥괴물 종류: 1스테이지 꼬마똥(기본), 물똥(빠르게 깡충), 단단똥(튼튼하고 화난 얼굴) / 2스테이지 그냥똥, 녹색똥
- **보스 분노**: 보스가 쉬지 않고 10대를 맞으면 빨갛게 달아오르며 2.6초 동안 무적("팅!")이 되고 똥을 세 번 연달아 퍼부어 반격합니다. 분노가 끝나면 6초 동안은 다시 분노하지 않습니다. (`enemy.gd` 의 `RAGE_HITS`, `RAGE_TIME`, `RAGE_COOLDOWN`)
- 스테이지 2 그림(그냥똥, 녹색똥, 무지개똥, 배경, 녹색/무지개 똥 덩어리, 시작 화면 그림, 시작 버튼)이 아직 없으면 기존 그림의 색을 바꿔서 대신 씁니다. 파일 이름: `enemies/plain_*`, `enemies/green_*`, `boss/rainbow_{normal,angry,hit,crit,rage,attack,down}`, `bg/bg_sewer2`, `props/poop_ball_green`, `props/poop_ball_rainbow`, `ui/title_key`, `ui/btn_start`
- 날아오는 똥 덩어리는 바닥 그림자로 떨어질 위치가 보이며, 뚜러뻥으로 공중에서 터뜨릴 수 있습니다.
- 앞쪽 **휴지 바리케이드**가 똥을 막아 주지만 맞을수록 무너집니다.
- 쓰러진 괴물이 가끔 아이템(휴지=목숨, 왕뚜러뻥)을 떨어뜨립니다. 뚜러뻥으로 맞히면 획득.

## 수정 포인트
- `scripts/main.gd`: `KILL_QUOTAS`(스테이지별 보스까지 처치 수), `BOSS_HP`, `RAINBOW_HP`
- `scripts/enemy.gd`: `COMBO_CRIT`(치명타까지 연속 타수), 괴물 종류별 체력/속도
- `scripts/sfx.gd`: 효과음/BGM 합성 (`pop` 이 변기 뚫리는 "펑!" 소리)
- `scripts/draw_util.gd`: 똥괴물 얼굴, 주인공, 변기 그림

## 파일 구성
```
project.godot, main.tscn
scripts/  main(흐름) player enemy plunger poop_ball barricade item fx bg hud cutscene sfx draw_util
fonts/    Jua-Regular.ttf, OFL.txt
art/      enemies(꼬마똥·물똥·단단똥 × 기본/화남/맞음/치명타/쓰러짐/던지기) hero boss props bg ui
```

## 핸드폰 (터치) 조작
- 화면을 누른 곳으로 뚜러뻥을 던집니다. 누르고 있으면 연사, 손가락을 끌면 조준이 따라옵니다.
- 왼쪽 아래 좌우 버튼으로 이동, 오른쪽 아래 버튼으로 구르기와 왕뚜러뻥.
- 가로 화면으로 해 주세요. 브라우저 메뉴의 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 열립니다.
